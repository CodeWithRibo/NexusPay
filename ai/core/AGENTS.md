## Mission
This repository is a learning platform backend using Laravel and Vue.

See:
- ./.ai/standard/
- ./.ai/features/


## Stack
- Laravel
- PHP
- Vue.js
- Inertia.js
- MySQL

## Coding Rules
- Prefer using service layer for reusable logic
- Follow the MVC architecture pattern
- Use Eloquent ORM for database interactions

## Behavior
- Ask before deleting files
- Keep responses concise
