## CONSISTENT UI/UX
- Don't change the UI/UX of the app unless it's necessary for a feature or bug fix.
- If you need to change the UI/UX, make sure to follow the existing design patterns and styles.
- Always consider the user experience when making changes to the UI/UX.
- Avoid making changes that could confuse or frustrate users.

## CONSISTENT Backend Architecture
- Follow the existing backend architecture and design patterns.
- Avoid introducing new architectural patterns unless it's necessary for a feature or bug fix.
- Always consider the maintainability and scalability of the backend when making changes.
- Avoid making changes that could introduce technical debt or make the codebase harder to maintain.
